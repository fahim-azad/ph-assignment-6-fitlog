# FitLog

## Project Description

FitLog is a no-nonsense gym companion application. FitLog allows users to browse a variety of workout routines with ease. FitLog lets users view metrics for each routine. FitLog lets users record workouts into their plan in a systematic way. Train with intent. Log every set.

## Technologies Used

- **Next.js (App Router)** – The main framework that handles server-side rendering, routing and dynamic data fetching.

- **Tailwind. Daisyui** – A utility-first CSS framework together with DaisyUI for nice responsive component styling.

- **React Hot Toast** – non-intrusive toast notifications.

- **Local Storage API** – Keeps user plans saved between sessions.

- **. Oswald Fonts** – Google Fonts integrated in Next.js for clear typography.

## 5 Key Features

1. **Dynamic API Integration** – FitLog automatically pulls workout routines, metrics and pictures from a REST API.

2. **My Plan Workspace** – FitLog offers a workspace where users can switch between the Todays Plan" and a separate "Saved" list.

3. **Advanced Workout Sorting** – FitLog lets users sort chosen routines by Duration, Calories. Rating, in ascending or descending order.

4. **Interactive Action Locking** – FitLog enforces a limit of 5 lifts by disabling buttons immediately. FitLog also stops users from adding exercises and shows custom toast error alerts.

5. **Persistent Progress Management** – FitLog lets users mark exercises as completed instantly. FitLog shows real-time totals such, as duration and calories burned. FitLog keeps all progress saved in storage even after a page reload.
